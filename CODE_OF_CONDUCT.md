# Code of Conduct

## Pledge

Everyone contributing here agrees to three things:

- **Accurate.** A number is a measurement, not an opinion. When something is
  wrong, say so and point at the run that shows it.
- **Traceable.** A timing comes with the prompt, the settings, the hardware and
  **the output file**. "It looked faster" is not a contribution.
- **Honest about licences.** "Downloadable" is not "commercially usable". A
  change that removes a licence warning from a model that needs one is rejected.

## Scope

Issues, pull requests, discussions and commit messages.

This repository holds a benchmark and the outputs it produced, not a community
product. Most disagreement is "did you hold the settings constant?" or "is that
number what the file actually shows?" — technical questions, answered with
evidence.

## Behaviour

Acceptable:

- Correcting a number with a reproduction
- Rejecting an addition and writing down why
- Reporting a leaked secret privately (see [`SECURITY.md`](SECURITY.md))

Not acceptable:

- Personal attacks, racism or sexualised harassment
- Adding a measurement you know to be fabricated
- Committing an output you did not generate, presented as if you had
- Publishing someone's API key or private host

## Enforcement

| Stage | Outcome |
| :--- | :--- |
| 1. Private warning | With a reason |
| 2. Temporary suspension | Reasoned and time-limited |
| 3. Permanent ban | Repeated or severe |

## Reporting

Email `irtibat@mahirfatih.com`. If the matter can be public, an issue is fine.
A reporter's name is not shared beyond the people involved.

## Attribution

These principles follow [Contributor Covenant 2.1](https://www.contributor-covenant.org/),
specialised for a generation benchmark: what matters here is **measurement
honesty**, **output provenance** and **licence accuracy**, which is why those
carry the pledge.
